# Core Modules

VukaSync OS should be organized around service modules. Each module should share
common platform primitives such as clients, projects, files, activities,
comments, reports, notifications, and permissions.

## 1. Social Media Management

Expected capabilities:

- Social media analytics.
- Activity tracking.
- Monthly reporting.
- Hybrid automatic and manual updates.
- Community engagement logs.
- Content calendars.
- Strategic notes and recommendations.

Initial design questions:

- Which social platforms are included first?
- Which metrics are synced through APIs and which are entered manually?
- How should reports distinguish automated data from human analysis?

## 2. Websites and Mobile Apps

Expected capabilities:

- Project progress tracking.
- Milestones.
- Requirements management.
- File sharing.
- Launch readiness and launch tracking.
- Client review and approval workflows.

Initial design questions:

- Which project templates are required?
- What milestone statuses should be standardized?
- How should client approvals be recorded?

## 3. Business Systems and Automation

Expected capabilities:

- CRM implementation tracking.
- Internal system projects.
- AI chatbot implementation tracking.
- Workflow automation projects.
- n8n workflow references and delivery status.

Initial design questions:

- How should automation workflows be represented in the portal?
- Which implementation artifacts should clients see?
- Which internal notes should remain staff-only?

## 4. Growth Services

Expected capabilities:

- Branding.
- Graphic design.
- SEO.
- Consulting.
- Future service lines.

Initial design questions:

- Which deliverable types are reusable across growth services?
- How should recurring strategy work be reported?
- Which assets need approval workflows?

## 5. Support and Resources

Expected capabilities:

- Support tickets.
- FAQs.
- Training materials.
- Meeting scheduling.
- Documentation.
- Client-facing resource libraries.

Initial design questions:

- What ticket categories and priorities are required?
- Which resources are global and which are client-specific?
- Which scheduling provider will be integrated first?
