# @vukasync/ui

Shared design tokens and future UI primitives for VukaSync OS.

## Current scope

The package currently exposes neutral foundation tokens and labels so apps can
consume shared workspace packages. Full design system components should be
introduced after design standards and cross-platform component boundaries are
agreed.

## Commands

```bash
pnpm --filter @vukasync/ui typecheck
pnpm --filter @vukasync/ui build
```
